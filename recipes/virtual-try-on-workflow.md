# Virtual Try-On Workflow

Choose the API that matches the garment structure instead of treating every try-on task as interchangeable:

- [AI Clothes Changer API for Tops & Bottoms](https://www.nexscope.ai/api-docs/ai-clothes-changer-for-tops-bottoms?co-from=githubcreative) for separate upper and lower garments.
- [AI Suit Virtual Try-On API](https://www.nexscope.ai/api-docs/ai-suit-virtual-try-on?co-from=githubcreative) for one-piece outfits.
- [Virtual Try-On API](https://www.nexscope.ai/api-docs/virtual-try-on?co-from=githubcreative) for the documented general product-on-model workflow.

Verify pose, body coverage, garment category, reference-image requirements, and file limits on the selected API page. Review fit, occlusion, hands, edges, logos, and product details before using the result.
